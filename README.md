# Стол заявок

Небольшая Help Desk-система на Java. Веб-интерфейс и REST API открываются на [http://localhost:8080](http://localhost:8080).

Отдельный сервер базы не нужен: заявки лежат в файле H2 в папке `data`. Входа по паролю нет — это локальный стол для одного оператора.

## Запуск

Нужны JDK 21 и Maven. Команду запускайте из этой папки:

```
mvn spring-boot:run
```

Сборка jar:

```
mvn package
java -jar target/helpdesk-1.0.0.jar
```

При первом запуске, если база пустая, добавляются демонстрационные заявки. Чтобы начать заново, остановите программу и удалите папку `data`.

Консоль H2: [http://localhost:8080/h2](http://localhost:8080/h2). JDBC URL: `jdbc:h2:file:./data/helpdesk`, пользователь `sa`, пароль пустой.

## Что есть в интерфейсе

- список заявок, поиск и фильтр по статусу и приоритету
- создание заявки
- смена статуса, приоритета и исполнителя
- комментарии

Статусы: открыта, в работе, ожидание, решена, закрыта.
Категории: оборудование, программы, доступ, сеть, другое.
Приоритеты: низкий, средний, высокий, критический.

## REST API

Справочник кодов: `GET /api/meta`.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/tickets` | Список. Параметры `status`, `priority`, `q` |
| POST | `/api/tickets` | Создать заявку |
| GET | `/api/tickets/{id}` | Заявка с комментариями |
| PATCH | `/api/tickets/{id}` | Статус, приоритет или исполнитель |
| POST | `/api/tickets/{id}/comments` | Комментарий |

Пример создания:

```json
{
  "subject": "Не работает почта",
  "description": "Outlook не подключается",
  "requesterName": "Иван Петров",
  "requesterEmail": "ivan@example.com",
  "category": "SOFTWARE",
  "priority": "HIGH"
}
```

Пустая строка в поле `assignee` снимает исполнителя. Комментарий: `{"author": "Марина", "body": "Проверила профиль"}`.
